# Teocalli PX7 — portafolio
Sitio estático (index.html + vendor/three.min.js). Sin build.
Animación con 3 motores automáticos: GPU (WebGL2) -> CPU+WebGL -> CPU+Canvas2D.
Para ver qué motor se usa: abrir el sitio con ?debug al final de la URL.
Para editar proyectos: arreglo PROJECTS dentro de index.html.
